# Журнал разработки NEXUS OSINT

## 1. Окружение и архитектура

- Проверены Arch Linux, Hyprland/Wayland, Python 3.14, Qt 6.12, SQLite и поиск FTS5.
- Первоначально DNS среды блокировал загрузку зависимостей. После восстановления сети PySide6 установлен в окружение проекта.
- Выбраны Qt Widgets, SQLite и фоновые задачи в одном приложении. GPU для локальных моделей не подтверждён.

## 2. Первый рабочий сценарий

- Проекты, заметки, хранилище материалов, отчёт Markdown и базовый граф.
- DNS A, Certificate Transparency и IP RDAP получили реальные ответы на контрольные запросы.
- Запуск и сквозной тест GUI прошли под Wayland. Подключены Ollama и OpenAI через отдельные клиенты.

## 3. Локальная память и анализ

- FTS5 подбирает фрагменты текущего проекта. Evidence Manager позволяет искать без сети.
- Сверяются дословные цитаты и сохраняются статусы утверждений. Смысл подтверждения проверяет аналитик.
- Режим «Авто» предлагает облачную модель для сравнительного анализа. Облачный вызов требует подтверждения.

## 4. Документы, копии и граф

- Добавлены PDF с текстовым слоем, DOCX, HTML, резервные копии SQLite и экспорт графа.
- Девять типов сущностей, связи с материалом и достоверностью, поиск и фильтрация графа, экспорт JSON и GraphML.
- Удаление проекта очищает рабочие записи и соответствующие фрагменты FTS. Проверены 13 тестов.

## 5. Гибридный режим и настройки

- Локальный анализ сохраняется перед возможным запросом к GPT. Обе части помечаются именем провайдера.
- Добавлены настройки Ollama и проектный журнал API. Проверены согласие и отказ от облачной отправки.
- 15 тестов прошли под Wayland. Локальный сервер Ollama и реальный ключ OpenAI пока недоступны.

## 6. Расширяемые источники

- Введён контракт источника с идентификатором, документацией ввода, валидатором ответа, HTTPS-хостом, интервалом и настройкой ключа. Модули подключаются через Python entry points. Search Hub показывает ошибки регистрации.
- Исполнитель соблюдает интервалы между запросами и ограничивает повторы временных ошибок. Добавлен ограниченный кэш публичных ответов с сохранением исходного времени получения.
- Проверены реальные ответы DNS A и CT для `iana.org`, а также RDAP для `8.8.8.8` через новый исполнитель.
- 20 тестов прошли под Wayland. Проверены обнаружение плагинов, отклонение некорректного ответа, повтор временного сбоя, кэш и сохранение происхождения в GUI.

## 7. Перенос отдельных расследований

- В Dashboard добавлены импорт и экспорт версионированного файла `.nexus.json`. Пакет включает заметки, материалы, сущности, связи и сохранённые утверждения анализа.
- Импорт создаёт отдельный проект, переназначает идентификаторы материалов в графе и цитатах и восстанавливает FTS. Повреждённая ссылка откатывает весь импорт.
- В рабочем формате предел 64 МиБ. Файлы содержат исходные URL и пути, текст и результаты анализа. Настройки провайдеров и журнал API остаются в исходной установке.
- 24 теста прошли под Wayland, включая экспорт и открытие копии через Dashboard, проверки пересчёта ссылок и отката.

## 8. Публичный репозиторий

- Для совместной разработки создан публичный репозиторий [stepa1235/nexus-osint](https://github.com/stepa1235/nexus-osint).
- В первый коммит включаются исходники, тесты, скрипт запуска и документация. Локальные базы, файлы проектов и настройки исключены.

## 9. История заметок

- В Dashboard добавлен просмотр предыдущих версий с датой и предпросмотром. Автосохранение обновляет текущую запись сразу, а серия правок создаёт один снимок предыдущего текста.
- Восстановление создаёт снимок заменённого текста. Версии из другого проекта отклоняются. При удалении проекта рабочая история удаляется вместе с ним.
- Формат `.nexus.json` переносит версии заметок. Пакеты, созданные до добавления истории, по-прежнему импортируются.
- 27 тестов прошли под Wayland, включая восстановление через GUI, изоляцию истории и совместимость пакетов.

## 10. Хронология и автоматическая проверка

- Вкладка «Хронология» хранит датированные события, описание и ссылку на материал. Записи без материала отображаются как гипотезы. Одинаковые названия с разными датами помечаются для проверки.
- Из события можно открыть сохранённый материал. Хронология входит в Markdown и `.nexus.json`. Старые пакеты открываются без дополнительной миграции.
- Подготовлен GitHub Actions workflow для push в main и pull requests. 28 тестов прошли локально на Wayland и Qt offscreen. Запуск на GitHub пока не подтверждён.

- Отмена выполняющейся задачи, дополнительные рабочие пространства и проверка производительности на больших корпусах.
